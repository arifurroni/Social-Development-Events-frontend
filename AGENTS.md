## What this repo is

Client-only Next.js 16 (App Router) app for the "TogetherWe" community-event assignment. **`README.md` is the requirements spec** — routes, auth flow, page sections, and the color palette/typography (#166534 / #16A36A / #F0FDF4 / #172B24, Inter) live there, not in code. The app is still a scaffold: `src/app/page.tsx` is an empty Home, and only `src/app/layout.tsx` exists as a route. The backend (Express/MongoDB/better-auth) is a separate project.

## Structure & conventions

- Path alias: `@/*` → `src/*` (tsconfig). Subdirs: `src/app`, `src/components`, `src/hooks`, `src/lib`.
- **shadcn/ui, style `base-nova`** (Base UI, not Radix) — see `components.json`. Add components with `npx shadcn add <name>`; generated code lands in `src/components/ui/` and is meant to be edited locally. `cn()` lives in `src/lib/utils.ts`.
- **Tailwind CSS v4, CSS-first**: no `tailwind.config`. All theme tokens are `@theme` / CSS variables in `src/app/globals.css`; it's wired via the `@tailwindcss/turbopack` loader rule in `next.config.ts`. Don't reintroduce a JS config.
- `next.config.ts` enables `cacheComponents: true` (Cache Components / `use cache` semantics — async data needs Suspense), `partialPrefetching`, and `reactCompiler: true`. Changing these changes build behavior; consult `node_modules/next/dist/docs/`.
- `LayoutProps<"/">` in `layout.tsx` is a global type generated by Next into `.next/types` — don't hand-define or "fix" it.
